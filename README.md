# KINETIX

KINETIX is a gym and yoga fitness website built with Flask, HTML, CSS and JavaScript.

## Features

- Gym exercise library
- Yoga pose library
- Calorie meter
- Body-part filters
- Exercise and yoga demo links
- Responsive design
- Modern gym theme
- Traditional yoga-inspired theme
